## 1. ゲーム概要

### コンセプト
日本の上場企業を選んでいき、合計時価総額が目標金額に最も近づいたプレイヤーが勝ち。  
**時価総額は常に非表示**。会社名だけを手がかりに規模を推測するのがゲームの本質。  
「超えたら失格（1人プレイ）」のスリルを持つ、**オリジナルルールのチキンレースゲーム**。

## 4. ゲームルール・終了条件

### 1人プレイ

- 表示された企業リストから自由に選択
- 制限時間：**5分**
- 企業リスト表示：**銘柄コード順・2列グリッド・会社名省略（末尾…）**
- 選択済み企業：**グレーアウトして残す**
- 選択済みリスト表示：**銘柄コード＋会社名**
- 合計金額：**非表示**
- 選択の取り消し：**不可**

| 終了条件 | 挙動 |
|----------|------|
| 5分経過 | 強制終了→結果表示 |
| 目標金額超過（ドボン） | ゲーム画面上で「ドボン！」表示→結果画面へ遷移 |
| ストップボタン押下 | 確認ダイアログ→「やめる」で終了→結果表示 |
| 全企業選択 | そのまま結果表示 |

### 2人対戦

- 同じ企業リストを見ながら**同時進行で自由に選択**（ターン制ではない）
- 同じ企業は**早い者勝ち**（両者が同時に選べない）
- 失格なし（目標金額を超えても続行可能）
- 合計金額：**非表示**
- 選択の取り消し：**不可**

#### マッチング方法
- URLまたはQRコードを共有してルームに入室
- 難易度：**ルーム作成者が選択**（待機画面からの変更不可）
- ゲーム開始：**ホストが開始ボタンを押す**（相手入室後に有効化）
- 相手の選択：**ボタンで切り替えてリアルタイム確認可能**

#### 終了条件

| 終了条件 | 挙動 |
|----------|------|
| 片方がストップボタン押下 | 確認ダイアログ→「はい」で決定。もう片方に**2分の制限時間**が発生 |
| 2分以内にもう片方がストップ | 両者の答え合わせへ |
| 2分経過（時間切れ） | 強制終了→答え合わせへ |
| 相手が切断 | 「相手が切断しました」と表示→ゲーム終了→結果画面へ（勝敗なし） |

#### 再戦
- 結果画面に「もう一度」ボタンを設置
- 同じルームIDでゲーム状態をリセットして再戦可能
- ルームの有効期限：**1〜2時間**

### 勝敗判定（2人対戦）

| 状況 | 判定 |
|------|------|
| 差額が近い方 | 勝ち |
| 差額が完全に同じ | 引き分け |
| 両者ともドボン | 引き分け（将来的に変更の可能性あり） |
| 片方のみドボン | ドボンしていない方の勝ち |

## 6. データ設計

### 企業リストの構成

- 元データ：`data/screener_result.csv`（リポジトリ内）
- CSVフォーマット：コード, 銘柄名, 市場, 現在値, 前日比(%), 時価総額(百万円)
- ゲーム開始時にCSVをfetchして全件読み込み（現状は全社表示、将来的に約100社に絞る予定）
- 毎日CSVを差し替えるだけでデータ更新される運用
- 検索・絞り込み機能はなし

### CSVの列構成（確定）

| 列名 | 内容 |
|------|------|
| コード | 銘柄コード |
| 銘柄名 | 会社名 |
| 市場 | 上場市場（ゲームでは不使用） |
| 現在値 | 株価（ゲームでは不使用） |
| 前日比(%) | 騰落率（ゲームでは不使用） |
| 時価総額(百万円) | 時価総額（ゲームで使用） |

> ※ゲームで使うのは「コード」「銘柄名」「時価総額(百万円)」の3列のみ。  
> ※列の前後にダブルクォートが付いていても正常にパースできる処理を実装済み。

### 基準日の表示
- ゲーム画面・結果画面に「直近の終値を参考」と表示する
- 特定の日付はハードコードしない

### CSV運用フロー

| フェーズ | 方法 |
|----------|------|
| 初期〜当面 | 毎日手動でCSVを差し替え（`data/screener_result.csv`） |
| 将来 | J-Quants API（日本取引所グループ公式）で前日終値を毎日18時に自動更新 |

## 8. Firebase設計

### 基本方針
- 1人プレイはFirebase不要（フロントエンドのみで完結）
- 2人対戦のリアルタイム同期にのみFirebase Realtime Databaseを使用
- プレイヤー識別はFirebase Anonymous認証を使用

### データ構造

```
rooms/
└── {roomId}/
    ├── status          # "waiting" | "playing" | "finished"
    ├── difficulty      # "easy" | "normal" | "hard"
    ├── targetAmount    # 100 | 50 | 10（兆円）
    ├── createdAt       # タイムスタンプ
    ├── expiresAt       # タイムスタンプ（createdAtから1〜2時間後）
    ├── companies/      # ホストが抽出した約100社
    │   └── {code}/
    │       ├── name        # 会社名
    │       └── marketCap   # 時価総額（百万円）
    ├── players/
    │   ├── host/
    │   │   ├── uid
    │   │   ├── connected
    │   │   ├── stopped
    │   │   ├── stoppedAt
    │   │   └── selections/
    │   │       └── {code}: true
    │   └── guest/
    │       ├── uid
    │       ├── connected
    │       ├── stopped
    │       ├── stoppedAt
    │       └── selections/
    │           └── {code}: true
    └── timer/
        ├── startedAt
        ├── triggerStopAt
        └── deadlineAt
```

## 9. 状態管理設計

### 方針
- **useContext + useReducer** を使用（外部ライブラリなし）
- 1人プレイ・2人対戦の状態を **1つのGameContextにまとめる**

### 画面とURLの対応

| URL | 画面 |
|-----|------|
| `/` | トップ画面 |
| `/select-mode` | 難易度選択（1人プレイ） |
| `/game` | ゲーム画面（1人プレイ） |
| `/result` | 結果画面（1人プレイ） |
| `/room/create` | ルーム作成・難易度選択（2人対戦） |
| `/room/:roomId` | ルーム待機画面 |
| `/room/:roomId/game` | ゲーム画面（2人対戦） |
| `/room/:roomId/result` | 結果画面（2人対戦） |
