## 1. ゲーム概要

### コンセプト
日本の上場企業を選んでいき、合計時価総額が目標金額に最も近づいたプレイヤーが勝ち。  
**時価総額は常に非表示**。会社名だけを手がかりに規模を推測するのがゲームの本質。  
目標金額を超えてしまうとドボン（失格）になる**オリジナルルールのチキンレースゲーム**。  
ただし**ドボンはゲーム中には分からず、結果画面を開いて初めて発覚**するのがスリルのポイント。

## 4. ゲームルール・終了条件

### 1人プレイ

- 表示された企業リストから自由に選択
- 制限時間：**5分**
- 企業リスト表示：**銘柄コード順・2列グリッド・会社名省略（末尾…）**
- 選択済み企業：**グレーアウトして残す**
- 選択済みリスト表示：**銘柄コード＋会社名＋仮計算入力欄**
- 合計金額：**非表示**（仮計算欄への手入力で自分で推測する）
- 選択の取り消し：**不可**
- 目標金額を超えてもゲームは続行できる。**ドボンはゲーム中には通知されず、結果画面を開いて初めて発覚する**

| 終了条件 | 挙動 |
|----------|------|
| 5分経過 | 強制終了→結果画面へ |
| ストップボタン押下 | 確認ダイアログ→「やめる」で終了→結果画面へ |
| 全企業選択 | そのまま結果画面へ |

### 2人対戦（ターン制）

- 同じ企業リスト（100社）を見ながら**交互に1社ずつ選択するターン制**
- 先行・後攻はゲーム開始時に**ランダム**で決定
- **1ターン＝1分**。1分以内に銘柄を選んだら**即座にターン交代**
- 1分経過しても選択しなかった場合は「時間切れなので相手のターンになります」ポップアップを表示して**自動でターン交代（パス扱い）**
- 相手のターン中は「相手のターン　少々お待ちください。」ポップアップを継続表示。タップはできるが選択確定は不可
- 相手が選んだ銘柄は**グレーアウト＋赤枠＋「相手選択済」**で表示（選択不可）
- 相手が銘柄を選んだ直後、**「相手は〇〇を選びました」トーストを数秒間表示**（自動で消える）
- **「相手のリスト」ボタン**で相手の選択済み銘柄一覧をいつでも確認可能
- 目標金額を超えてもゲームは続行できる（ドボンは結果画面で初めて発覚）
- 合計金額：**非表示**
- 選択の取り消し：**不可**

#### マッチング方法
- **URL共有** または **QRコード** のどちらでも入室可能
- 難易度：**ルーム作成者（ホスト）が選択**（待機画面からの変更不可）
- ゲーム開始：**ホストが開始ボタンを押す**（ゲスト入室後に有効化）
- プレイヤー名：**「ホスト」「ゲスト」固定表示**
- ゲスト側の画面遷移：URLを踏む →「現在、ルームを作成しています。少々お待ちください。」画面 → ゲーム開始で自動遷移

#### 終了条件

| 終了条件 | 挙動 |
|----------|------|
| 自分がSTOPボタン押下 | 確認ダイアログ→「やめる」で決定。以降は見守るだけ・選択不可。相手に**2分の制限時間**が発生 |
| 2分以内に相手がSTOP | 両者の答え合わせへ |
| 2分経過（時間切れ） | 強制終了→答え合わせへ |
| 相手が切断 | 「相手が切断しました」と表示→結果画面へ（勝敗なし） |

#### 再戦
- 結果画面「もう一度」→ルーム待機画面に戻る（同じルームIDで再利用）
- ルームの有効期限：**1〜2時間**

### 勝敗判定（2人対戦）

| 状況 | 判定 |
|------|------|
| 差額が近い方 | 勝ち |
| 差額が完全に同じ | 引き分け |
| 両者ともドボン | 引き分け（将来的に変更の可能性あり） |
| 片方のみドボン | ドボンしていない方の勝ち |

- プレイヤー識別はFirebase Anonymous認証

### Firebaseプロジェクト情報
- プロジェクトID：`chicken-race-d0006`
- Realtime Database URL：`https://chicken-race-d0006-default-rtdb.asia-southeast1.firebasedatabase.app`
- リージョン：asia-southeast1（シンガポール）

### データ構造（ターン制対応版）

```

└── {roomId}/
    ├── status          # "waiting" | "playing" | "finished"
    ├── difficulty      # "easy" | "normal" | "hard"
    ├── targetAmount    # 100 | 50 | 10（兆円）
    ├── createdAt
    ├── expiresAt       # createdAtから2時間後
    ├── companies/
    │   └── {code}/
    │       ├── name
    │       ├── oku
    │       └── cho
    ├── turn/
    │   ├── current     # "host" | "guest"（現在のターンプレイヤー）
    │   └── startedAt   # 現在のターン開始タイムスタンプ（1分タイマー用）
    ├── players/
    │   ├── host/
    │   │   ├── uid
    │   │   ├── connected
    │   │   ├── stopped
    │   │   ├── stoppedAt
    │   │   └── selections/{code}: true
    │   └── guest/
    │       ├── uid
```

## 13. 引継ぎメモ（次チャットへの申し送り）

### 引継ぎ方法
次のチャットでは以下の2つをセットで渡すこと：
1. **このMDファイル**を添付
2. **`chicken-race.html`** を添付

### HTMLの構成メモ
- 画面コンポーネント：`LoadingScreen` / `ErrorScreen` / `TopScreen` / `DifficultyScreen` / `GameScreen` / `ResultScreen` / `GuestWaitScreen` / `RoomWaitScreen` / `VsGameScreen` / `VsResultScreen`
- `App` コンポーネントで `screen` stateにより画面切り替え
- 各コンポーネントの境界に `// ========` コメントあり
- 高さ指定は `100dvh`・横スクロール禁止済み

### ターン制の実装メモ
- Firebaseの `rooms/{roomId}/turn/current` でどちらのターンかを管理
- `turn/startedAt` に現在のターン開始時刻を保存し、1分タイマーをクライアント側で計算
- ターン交代はFirebaseのtransactionで排他制御（両者が同時に書き込まないように）
- 先後決定：ホストがゲーム開始時にランダムで `turn/current` を "host" or "guest" に設定

### Firebase設定メモ
- HTMLの `<script>` タグ（Babel外）に `firebaseConfig` を直書き
- `firebase.initializeApp()` → `auth` と `db` をグローバル変数として定義
- Anonymous認証：起動時に `auth.signInAnonymously()` を呼ぶ
- ホストのUID取得は `auth.currentUser.uid` を直接参照
- ゲスト入室：URLパラメータ `?room={roomId}` を検出して自動入室
- 切断検知：`myConRef.onDisconnect().set(false)` で登録

### CSV注意事項
- 時価総額(兆円)は小数で表現（例：0.571631）
- BOM付きUTF-8・クォート囲みフィールド対応済み
- ランクCDは1〜7の整数

### fmt関数の実装注意
- `addComma(triVal.toFixed(2))` は小数点をセパレータと誤認するためNG
- 正：`toFixed(2)` → 小数点で分割 → 整数部分のみカンマ → 結合

## 4. ゲームルール・終了条件

### 1人プレイ

- 表示された企業リストから自由に選択
- 制限時間：**5分**
- 企業リスト表示：**銘柄コード順・2列グリッド・会社名省略（末尾…）**
- 選択済み企業：**グレーアウトして残す**
- 選択済みリスト表示：**銘柄コード＋会社名＋仮計算入力欄**
- 合計金額：**非表示**（仮計算欄への手入力で自分で推測する）
- 選択の取り消し：**不可**
- 目標金額を超えてもゲームは続行できる。**ドボンはゲーム中には通知されず、結果画面を開いて初めて発覚する**

| 終了条件 | 挙動 |
|----------|------|
| 5分経過 | 強制終了→結果画面へ |
| ストップボタン押下 | 確認ダイアログ→「やめる」で終了→結果画面へ |
| 全企業選択 | そのまま結果画面へ |

#### 終了条件

| 終了条件 | 挙動 |
|----------|------|
| 片方がストップボタン押下 | 確認ダイアログ→「やめる」で決定。もう片方に**2分の制限時間**が発生。STOP済みの側は操作不可 |
| 2分以内にもう片方がストップ | 両者の答え合わせへ |
| 2分経過（時間切れ） | 強制終了→答え合わせへ |
| 相手が切断 | 「相手が切断しました」と表示→結果画面へ（勝敗なし） |

#### 再戦
- 結果画面「もう一度」→ルーム待機画面に戻る（同じルームIDで再利用）
- ルームの有効期限：**1〜2時間**

### 勝敗判定（2人対戦）

| 状況 | 判定 |
|------|------|
| 差額が近い方 | 勝ち |
| 差額が完全に同じ | 引き分け |
| 両者ともドボン | 引き分け（将来的に変更の可能性あり） |
| 片方のみドボン | ドボンしていない方の勝ち |

## 13. 引継ぎメモ（次チャットへの申し送り）

### 引継ぎ方法
次のチャットでは以下の2つをセットで渡すこと：
1. **このMDファイル**を添付
2. **`chicken-race.html`** を添付

### HTMLの構成メモ
- 画面コンポーネント：`LoadingScreen` / `ErrorScreen` / `TopScreen` / `DifficultyScreen` / `GameScreen` / `ResultScreen` / `RoomWaitScreen` / `VsGameScreen` / `VsResultScreen`
- `App` コンポーネントで `screen` stateにより画面切り替え
- 各コンポーネントの境界に `// ========` コメントあり
- 高さ指定は `100dvh`・横スクロール禁止済み

### Firebase設定メモ
- HTMLの `<script>` タグ（Babel外）に `firebaseConfig` を直書き
- `firebase.initializeApp()` → `auth` と `db` をグローバル変数として定義
- Anonymous認証：起動時に `auth.signInAnonymously()` を呼ぶ
- ホストのUID取得は `auth.currentUser.uid` を直接参照（`uid` stateが未セットの場合に備えて）
- ゲスト入室：URLパラメータ `?room={roomId}` を検出して自動入室
- 切断検知：`myConRef.onDisconnect().set(false)` で登録

### CSV注意事項
- 時価総額(兆円)は小数で表現（例：0.571631）
- BOM付きUTF-8・クォート囲みフィールド対応済み
- ランクCDは1〜7の整数

### fmt関数の実装注意
- `addComma(triVal.toFixed(2))` は小数点をセパレータと誤認するためNG
- 正：`toFixed(2)` → 小数点で分割 → 整数部分のみカンマ → 結合
