## 1. ゲーム概要

### コンセプト
日本の上場企業を選んでいき、合計時価総額が目標金額に最も近づいたプレイヤーが勝ち。  
**時価総額は常に非表示**。会社名だけを手がかりに規模を推測するのがゲームの本質。  
目標金額を超えてしまうとドボン（失格）になる**オリジナルルールのチキンレースゲーム**。  
ただし**ドボンはゲーム中には分からず、結果画面を開いて初めて発覚**するのがスリルのポイント。

## 4. ゲームルール・終了条件

### 1人プレイ

- 表示された企業リストから自由に選択
- 制限時間：**5分**
- 企業リスト表示：**銘柄コード順・2列グリッド・会社名省略（末尾…）**
- 選択済み企業：**グレーアウトして残す**
- 選択済みリスト表示：**銘柄コード＋会社名＋仮計算入力欄**
- 合計金額：**非表示**（仮計算欄への手入力で自分で推測する）
- 選択の取り消し：**不可**
- 目標金額を超えてもゲームは続行できる。**ドボンはゲーム中には通知されず、結果画面を開いて初めて発覚する**

| 終了条件 | 挙動 |
|----------|------|
| 5分経過 | 強制終了→結果画面へ |
| ストップボタン押下 | 確認ダイアログ→「やめる」で終了→結果画面へ |
| 全企業選択 | そのまま結果画面へ |

### 2人対戦

- 同じ企業リストを見ながら**同時進行で自由に選択**（ターン制ではない）
- 同じ企業は**早い者勝ち**（両者が同時に選べない）
- 目標金額を超えてもゲームは続行できる（1人プレイと同じ）
- 合計金額：**非表示**
- 選択の取り消し：**不可**

#### マッチング方法
- URLまたはQRコードを共有してルームに入室
- 難易度：**ルーム作成者が選択**（待機画面からの変更不可）
- ゲーム開始：**ホストが開始ボタンを押す**（相手入室後に有効化）
- 相手の選択：**ボタンで切り替えてリアルタイム確認可能**

#### 終了条件

| 終了条件 | 挙動 |
|----------|------|
| 片方がストップボタン押下 | 確認ダイアログ→「はい」で決定。もう片方に**2分の制限時間**が発生 |
| 2分以内にもう片方がストップ | 両者の答え合わせへ |
| 2分経過（時間切れ） | 強制終了→答え合わせへ |
| 相手が切断 | 「相手が切断しました」と表示→ゲーム終了→結果画面へ（勝敗なし） |

#### 再戦
- 結果画面に「もう一度」ボタンを設置
- 同じルームIDでゲーム状態をリセットして再戦可能
- ルームの有効期限：**1〜2時間**

### 勝敗判定（2人対戦）

| 状況 | 判定 |
|------|------|
| 差額が近い方 | 勝ち |
| 差額が完全に同じ | 引き分け |
| 両者ともドボン | 引き分け（将来的に変更の可能性あり） |
| 片方のみドボン | ドボンしていない方の勝ち |

## 6. データ設計

### 企業リストの構成

- 元データ：`data/screener_result.csv`（リポジトリ内）
- ゲーム開始時にCSVをfetchして全件読み込み
- ランクCD別にランダム抽出して**合計100社**を表示
- 毎日CSVを差し替えるだけでデータ更新される運用
- 検索・絞り込み機能はなし

### CSVの列構成（確定）

| 列名 | 内容 |
|------|------|
| コード | 銘柄コード |
| 銘柄名 | 会社名 |
| 市場 | 上場市場（ゲームでは不使用） |
| 時価総額(百万円) | （ゲームでは不使用） |
| 時価総額(億円) | 億円単位の時価総額（ゲームで使用） |
| 時価総額(兆円) | 兆円単位の時価総額（ゲームで使用・ドボン判定に使用） |
| ランクCD | 規模帯ランク番号（1〜7の整数） |
| ランク | ランク名称（表示には使用しない） |

> ※数値フィールドにカンマ（桁区切り）を含めない  
> ※時価総額(兆円)は小数で表現（例：0.571631）  
> ※CSVはBOM付きUTF-8でもパース可能（BOM対応済み）  
> ※クォートで囲まれたフィールドにも対応済み

## 8. Firebase設計

### 基本方針
- 1人プレイはFirebase不要（フロントエンドのみで完結）
- 2人対戦のリアルタイム同期にのみFirebase Realtime Databaseを使用
- プレイヤー識別はFirebase Anonymous認証を使用

### データ構造

```
rooms/
└── {roomId}/
    ├── status          # "waiting" | "playing" | "finished"
    ├── difficulty      # "easy" | "normal" | "hard"
    ├── targetAmount    # 100 | 50 | 10（兆円）
    ├── createdAt       # タイムスタンプ
    ├── expiresAt       # タイムスタンプ（createdAtから1〜2時間後）
    ├── companies/      # ホストが抽出した100社
    │   └── {code}/
    │       ├── name
    │       ├── oku     # 時価総額（億円）
    │       └── cho     # 時価総額（兆円）
    ├── players/
    │   ├── host/
    │   │   ├── uid
    │   │   ├── connected
    │   │   ├── stopped
    │   │   ├── stoppedAt
    │   │   └── selections/
    │   │       └── {code}: true
    │   └── guest/
    │       ├── uid
    │       ├── connected
    │       ├── stopped
    │       ├── stoppedAt
    │       └── selections/
    │           └── {code}: true
    └── timer/
        ├── startedAt
        ├── triggerStopAt
        └── deadlineAt
```

## 13. 引継ぎメモ（次チャットへの申し送り）

### 引継ぎ方法
**次のチャットでは以下の2つをセットで渡すこと：**

1. **このMDファイル**（本ファイル）を添付
2. **`chicken-race.html`** を添付（最新の実装コードが入っている）

そのうえで「このMDと HTML の続きを作ってください」と伝えればすぐ再開できる。

### HTMLの実装メモ
- React 18（CDN）+ Babel（CDN）で動作
- フォント：Sawarabi Mincho（Google Fonts）
- 画面：`LoadingScreen` / `ErrorScreen` / `TopScreen` / `DifficultyScreen` / `GameScreen` / `ResultScreen`
- `App` コンポーネントで画面遷移を管理（`screen` stateで切り替え）
- 各コンポーネントの境界に `// ========` コメントあり
- 高さ指定は `100dvh`・横スクロール禁止済み

### CSV注意事項
- 数値フィールドにカンマ（桁区切り）を含めない
- 時価総額(兆円)は小数で表現（例：0.571631）
- BOM付きUTF-8・クォート囲みフィールド対応済み
- ランクCDは1〜7の整数

### fmt関数（数値表示）の実装注意
- 兆円表示は整数部分のみカンマ、小数点以下はそのまま
- `toFixed(2)` で文字列化 → 小数点で分割 → 整数部分にカンマ → 結合
- `addComma(triVal.toFixed(2))` は小数点をセパレータと誤認するためNG

### 本番化（React + Vite）への移植時の注意
- Vite + Tailwind CSS + React Router でプロジェクト作成済み（ローカル環境）
- 2人対戦追加時に Firebase SDK を導入する
